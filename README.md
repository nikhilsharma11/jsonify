# jsonify

A modern JSON toolkit — format, diff, and generate data classes from raw JSON, all in your browser.

## Features

- **Syntax Highlighting** — Color-coded keys, strings, numbers, booleans, and nulls
- **Formatted View** — Pretty-printed JSON with line numbers and collapsible sections
- **Tree View** — Interactive, expandable tree with type-colored values
- **JSON Diff** — Side-by-side comparison with inline difference highlighting
- **Data Class Generation** — Convert JSON to Kotlin, Swift, or TypeScript data classes
- **Copy & Minify** — One-click copy of formatted output or minified JSON
- **Auto-Format** — Formats on paste and 300ms after you stop typing
- **Error Detection** — Pinpoints JSON syntax errors with line and column numbers

## Usage

Open `index.html` in any modern browser. No build step, no dependencies, no server required.

## Tech Stack

Single HTML file with embedded CSS and JavaScript. Zero dependencies.
